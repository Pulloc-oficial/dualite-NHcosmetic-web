# Dualité - Cosmética Natural y Holística

![Dualité Logo](public/logo.png)

Sitio web corporativo para Dualité, marca de cosmética natural con enfoque holístico.

## Stack Tecnológico
- React + Vite
- Tailwind CSS
- Framer Motion
- React Router

## Instalación
```bash
git clone https://github.com/tu-usuario/duality-cosmetics-web.git
cd duality-cosmetics-web
npm install
npm run dev
